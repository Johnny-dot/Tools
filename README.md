# KBTools

## Overview
KBTools is a collection of utility tools built with Python and Qt (PySide6). The
application bundles several features such as build helpers and asset analysis. All
required Python packages are listed in `requirements.txt`.

## Installation
It is recommended to use a virtual environment. After activating the environment,
install the dependencies with:

```bash
pip install -r requirements.txt
```

## Running the Application
Launch the Qt interface by executing `Main.py`:

```bash
python Main.py
```

## Documentation
Additional notes and legacy documents are available under the `docs/` directory.
